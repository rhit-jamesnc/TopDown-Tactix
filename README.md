# TopDown-Tactix

A high-performance, real-time 2D multiplayer soccer engine built to explore deterministic physics synchronization and state management in web-based games.

## Architecture

- **Frontend:** React, TypeScript, Matter.js (Physics)
- **Backend:** Node.js, Socket.io (Real-time state synchronization)
- **Monorepo:** Organized workspace allowing type-sharing between the React client and the Node.js server.
- **Physics Engine:** Custom 2D simulation featuring gravity-free rigid bodies, collision sensor detection, and deterministic state-resetting logic for gameplay consistency.

## Project Status

- **Physics Core:** Fully implemented and tested with deterministic boundary constraints.
- **Rendering:** Responsive canvas-based UI with dynamic scaling for various viewports.
- **State Management:** Real-time goal detection and automated pitch-reset logic for seamless gameplay loops.
